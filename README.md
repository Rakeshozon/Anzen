# **App Name**: Dekho India

## Core Features:

- Location Selection: Allow users to select Country → State → City to filter attractions.
- Attraction Categories: Display attractions in categories like Museums, Waterfalls, Forts, Parks, and Temples.
- Attraction Details: Show a short description, beautiful images, and the Google Maps location for each attraction.
- User Ratings and Reviews: Implement a system for users to rate and review attractions, including an AI powered tool to moderate spam and generate summaries.
- Featured Cities: Showcase featured cities on the home page for quick access.
- Responsive Design: Ensure the website is mobile-friendly and responsive across different devices.
- Map Integration: Integrate Google Maps to display the exact location of each attraction.

## Style Guidelines:

- Primary color: Saffron (#FF9933) to reflect the vibrancy of India.
- Background color: Light beige (#F5F5DC), a very desaturated saffron, for a neutral and clean backdrop.
- Accent color: Green (#32CD32) to add freshness and balance, analogous to saffron, for calls to action.
- Body and headline font: 'PT Sans' (sans-serif) for a modern yet friendly feel.
- Minimalist design with a focus on clear visuals and concise content.
- Use simple and intuitive icons for categories and navigation.
- Smooth transitions and subtle animations to enhance user experience.
